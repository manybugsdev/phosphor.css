# Maintenance notes

phosphor.css is a classless CSS library: it styles plain semantic HTML elements only.

## Rules

- Never require classes. Theme switching uses `data-theme` on `<html>` only.
- `src/phosphor.css` is the source of truth. `dist/` is generated by `npm run build` and committed so the demo and CDN links work; rebuild before every commit that touches `src/`.
- modern-normalize is vendored at build time (devDependency). Do not edit it; bump the version instead.
- All tokens are `--term-*` custom properties on `:root`. Add new themes as `:root[data-theme='name']` blocks that override tokens only.
- Every animation must be disabled under `prefers-reduced-motion: reduce`.
- Keep `print` styles free of CRT effects.
- When adding element styles, add the element to `index.html` so the demo covers everything.
- All documentation, comments and commit messages are in English.
