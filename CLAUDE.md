# Maintenance notes

termalize.css is a classless CSS library: it styles plain semantic HTML elements only.

## Rules

- Never require classes and never add theme switches (`data-theme` etc.).
- `src/termalize.css` is the source of truth. `dist/` is generated by `npm run build` and committed so the demo and CDN links work; rebuild before every commit that touches `src/`.
- modern-normalize is vendored at build time (devDependency). Do not edit it; bump the version instead.
- All tokens are `--term-*` custom properties on `:root`. Users recolor by setting `color` and `background-color` on `html` only; derive every other color from `currentColor` (`color-mix()`, `inherit`). Never reference the background color in another property and never hard-code theme colors outside `html` and `print`. Light/dark is driven by `color-scheme` on `html` (default `light dark`); use `light-dark()` where a derived value must differ per scheme.
- Every animation must be disabled under `prefers-reduced-motion: reduce`.
- Keep `print` styles free of CRT effects.
- When adding element styles, add the element to `index.html` so the demo covers everything.
- All documentation, comments and commit messages are in English.

## Commits

- Write commit messages in [Conventional Commits](https://www.conventionalcommits.org/) format: `type(scope): summary` (e.g. `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`). Mark breaking changes with `!` and a `BREAKING CHANGE:` footer.
